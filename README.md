##  Présentation du Projet :

Ce dépôt regroupe nos travaux réalisés dans le cadre du cours sur les **langages de balisage léger**. 

Nous avons choisi de traiter le sujet des **Guerres Napoléoniennes (1803–1815)** en combinant deux formats de balisage :
* **Markdown** : Pour la structure et la documentation du dépôt GitHub (ce fichier `README.md`).
* **MediaWiki / Wikitexte** : Pour la rédaction de l'encyclopédie détaillée située dans l'onglet **Wiki** du dépôt.

---

##  Structure de la Documentation (Wiki) :

Notre Wiki est structuré en plusieurs pages interconnectées :

1. **Page Principale (`Home`)** : Vue d'ensemble des 7 coalitions, du contexte de 1803 jusqu'à Waterloo en 1815.
2. **[Bataille d'Austerlitz]** : Focus sur la stratégie militaire du 2 décembre 1805 (plateau de Pratzen).
3. **[Campagne de Russie]** : Analyse du tournant stratégique de 1812 et de la retraite de la Grande Armée.
